
# NovaWatch - Smart Watch Landing Page

## About the Project

NovaWatch is a simple product landing page for a smart watch. It is created using HTML and CSS.

The website provides information about the product, its features, benefits, customer reviews, and pricing.

## Features

- Simple navigation bar
- Product introduction section
- Product image
- Features section
- Benefits section
- Customer reviews section
- Pricing section with a Buy Now button
- About section
- Responsive design for mobile screens

## Technologies Used

- HTML - To create the structure of the website
- CSS - To style the website and make it responsive

## How to Run the Project

1. Download or copy the project files into a folder.
2. Open the folder in Visual Studio Code.
3. Open the index.html file in a web browser.
4. You can also use the Live Server extension in VS Code.

## How It Works

The navigation links take users to different sections of the same page.
The Buy Now button displays a message when clicked.
The website uses CSS Flexbox to adjust the layout for smaller screens.
